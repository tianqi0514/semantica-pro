# 采购合规演示操作速查卡

## 主演示：规则模式，约 15–20 分钟

1. 打开 `http://121.196.149.55:9009/` 并登录。
2. `Documents -> 模型配置`：只展示 `kimi-k3` 和密钥已配置状态。
3. `Documents -> 场景模板`：依次展示三个内置模板的实体与关系定义。
4. `Documents -> 文档抽取`：一次选择 `10-上传材料` 中的三个文件。
5. 勾选：采购合规审查、供应商风险画像、合同关键要素。
6. 选择“规则抽取”。
7. 确认页面显示 3 个文件 × 3 个模板 = 9 个任务。
8. 点击开始，讲解真实阶段进度和独立子任务。
9. 完成后先看合并结果：3 文档、48 实体、6 关系、0 失败。
10. 按模板筛选：
    - 采购合规审查：20 实体、6 关系。
    - 供应商风险画像：26 实体、2 关系。
    - 合同关键要素：28 实体、0 关系。
11. 看“原文预览”“实体”“关系”，核对李明持股关系的证据。
12. 下载 JSON 和 CSV。
13. 只有确认允许写图谱时，才到 `Enrich -> Import and Export -> Upload to Graph` 导入 JSON。

## 可选演示：Kimi，约 4–8 分钟

1. 只上传 `3-采购合同关键条款确认稿.txt`。
2. 只选“合同关键要素”。
3. 选择 Kimi K3。
4. 任务数必须是 1。
5. 重点核对合同主体、金额、日期、条款和义务关系，不承诺固定数量。

## 三句必须讲清楚的话

- 抽取结果是带证据的候选知识，不是最终合规结论。
- 多模板是分别执行后合并，不是把三套定义拼成一个提示词。
- 合同模板规则模式的关系为 0，是因为当前没有关系正则；这是真实实现边界。
